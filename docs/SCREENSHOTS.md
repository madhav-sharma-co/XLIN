# Screenshots for the README

Take them with `xlin screenshot full` (Shift+Print), upload them to a GitHub issue or the README
editor to get an image link, or copy them into `docs/img/`.

Suggested set (light and dark of each): desktop with the Run Bar and a terminal, the Launcher,
the control panel, Settings, Files, and the lock screen. Use a clean wallpaper and hide personal
files.
