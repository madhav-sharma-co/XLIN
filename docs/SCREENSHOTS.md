# Screenshots for the README

Good screenshots sell a desktop. Take them with `xlin screenshot full` (Shift+Print), then
copy them from `~/Pictures/Screenshots` into `docs/img/`.

Suggested set (light and dark of each):
1. Desktop with the dock and a terminal open
2. Launcher open (Super+Space)
3. Control panel (Super+C) and battery menu (Super+B)
4. Settings, Files and Notes windows
5. Lock screen (Super+L; use a second device or a recording to capture it)

Use a clean wallpaper, hide personal files, and name them `desktop-light.png`,
`desktop-dark.png` and so on, then link them near the top of README.md.
